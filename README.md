# Muhammad Saqeeb for East Brunswick Board of Education

Campaign website for Muhammad Saqeeb, candidate for the East Brunswick Board of Education.

## Stack

- React 19 + TanStack Start (Vite 7)
- Tailwind CSS v4
- Recharts for budget and data visualizations
- Postgres backend for volunteer signups, contact messages, and admin analytics

## Local development

```sh
npm install
npm run dev
```

The app runs on http://localhost:8080.
